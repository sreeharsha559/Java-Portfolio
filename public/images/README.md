Drop your portrait here so the hero section picks it up automatically.

Accepted names (checked in this order):

```
public/images/hero-portrait.webp   (recommended — smallest, sharpest)
public/images/hero-portrait.png    (use this if your image has transparency)
public/images/hero-portrait.jpg
```

# Tips for a premium result

1. Use a clear, front-facing photo, well lit.
2. Ideally upload a PNG with the background already removed.
   If you only have a photo WITH a background, that is fine too — the site
   applies a soft radial mask that dissolves the edges into the dark theme,
   plus a blue glow, so it blends in naturally.
3. For best performance, keep the image under ~500 KB and roughly square
   (e.g. 1024x1024 is plenty).
4. Free background removal: Photoshop, remove.bg, or any online bg remover.
   Export as PNG (transparency) or WebP.

Until a portrait exists, the site shows a stylish "HS" monogram card as a
placeholder — everything else still works and the build never breaks.
